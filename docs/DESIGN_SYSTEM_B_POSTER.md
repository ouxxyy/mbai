# MBAI 身份海报与报告（5.0）

## 视觉方向

沿用黑 #0D0D0D、亮黄 #EBFB3B、橙 #FF4A00 与现有 3D 工牌绒绒形象。12 类已逐项核对：保留 8 张匹配形象，重绘沟通、推进、决策、个案服务 4 张。名称、定义与素材绑定的唯一目录为 scripts/role_match.py。

## HTML

首屏角色与指数 → 替代处境结论 → 具体任务分工 → 优势与边界 → 三个行动 → 补充技能证据 → 分享卡 → 方法说明。指数方向采用先取整、后取补，不重算 JSON。

新形象使用白底完整立像，旧透明素材在白底展台呈现；避免文字工牌乱码。角色判定理由与置信度可见；角色可以已归类但暂无指数。信息不足不能出现伪造的数字。高分表述当前任务特点，不能承诺安全。说明“分数越高，当前工作越依赖人的判断、协作或现场处理”。

## 分享卡

1080×1440，顶部 MBAI，外号与处境定义居前，中间形象与指数，下方本案分享句与脱敏依据。分享句是视觉重心，说明文字精简。保留“搜 欧八同学 生成自己的职业AI体检报告”引导语。

不显示英文等级、内部 code、取整常量、任务分工表或行动计划。低置信角色明确“暂按现有描述归类”。卡片正文与价值句必须通过隐私门禁，图片需 OCR 验收。

## 运行与验收

只嵌入当前角色与品牌资产；图片解码失败明确中止导出，不换成其他角色。HTML 离线运行；窄屏无横向溢出。PNG 不带隐藏文本块，导出尺寸固定。外号无稀有人群比例，角色与分数独立。

## 品牌与卡面修订

品牌统一使用 MBAI 大写几何字标，四字母构成一个完整标识；卡头只展示一次。正式资产为 assets/brand/svg/MBAI_wordmark.svg，旧小写资产仅保留历史兼容，不再用于报告。等级条、金句左侧与底部「欧八同学」使用红橙色 #FF4A00 点缀。删除「工作方式图鉴」「我的工作方式」等无信息标题；指数解释直接说明高低分代表的含义。
